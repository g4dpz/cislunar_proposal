## Notes

- The IPNSIG SSI report provides institutional backing for RADIANT's architecture choices (BPv7 + LTP + CGR)
- KPLO proves that Bundle Protocol is operational at the Moon today (since 2022)
- LunaNet defines the interoperability standard RADIANT aims to be compatible with
- µD3TN and Hardy are candidate flight software for RADIANT's CubeSat phases
- The IETF TVR Working Group is directly relevant to RADIANT's contact graph routing work
- ESA Moonlight is the commercial cislunar infrastructure RADIANT could eventually interoperate with
